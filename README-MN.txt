LEARNMINEA — НОМЫН КАРТЫН ЗАСВАР

1. Supabase SQL Editor дээр supabase-short-description.sql-г нэг удаа ажиллуул.
2. ZIP доторх app/... файлуудыг төслийн root хавтсанд задал (unzip -o ... -d ~/learn-minea).
3. npm run build ажиллуул. Хэрэв build амжилттай бол dev server restart хийнэ.
4. Админ /admin/books хэсэгт Богино тайлбар талбар гарна. Тайлбар оруулаад хадгал.
5. Нүүр хуудасны карт дээр богино тайлбар, үнэ, Захиалах товч харагдана. Карт бүхэлдээ /books/[id] рүү шилжинэ.

ЧУХАЛ: Нүүр хуудасны номын өгөгдлийг app/page.js доторх getPublishedCatalog() дамжуулж байгаа. Хэрэв богино тайлбар хадгалагдсан мөртлөө карт дээр харагдахгүй бол app/lib/publicCatalog... (эсвэл catalog mapper) short_description талбарыг дамжуулахгүй байна гэсэн үг. Тэр файлыг шалгах шаардлагатай. Энэ ZIP-д байхгүй mapper-ийг таамгаар өөрчлөөгүй.

Өмнөх кодоо backup хийгээд соль. Энэ ZIP нь зөвхөн 3 JS файлыг өөрчилнө.
